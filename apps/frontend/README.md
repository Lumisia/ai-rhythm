# 로컬 채보 플레이테스터

이 앱은 `playtest-run-v1.json`이 있는 로컬 워커 실행 폴더를 서버 업로드 없이 검사하고 수동 플레이하는 도구다.

## 브라우저 실행 전 검증

Node.js 24 환경에서 다음 명령으로 실행 폴더를 먼저 검사한다.

```powershell
npm run validate:run -- "C:\Git\ai-rhythm\.data\playtests\koe-no-yukue-real"
```

검증기는 매니페스트가 참조하는 오디오와 12개 채보만 읽는다. JSON Schema, SHA-256, 키 모드·난이도 조합, 노트 시간과 레인, HOLD 종료 시각, 지표의 노트 수를 확인한다. 난이도 목표 초과, 측정 티어 불일치, 난이도 간 rating 역전은 실패가 아니라 수동 확인용 경고로 출력한다.

## 수동 플레이 순서

브라우저 검증을 시작할 때 `npm run dev`를 실행하고 워커 실행 폴더를 선택한다. 공통 타이밍과 입력감을 비교하기 위해 다음 순서를 권장한다.

1. NORMAL 4K
2. NORMAL 6K
3. NORMAL 7K
4. 각 키 모드의 EASY → HARD → EXPERT

플레이 중 숫자 키로 문제 구간을 기록한다.

- `1`: 박자
- `2`: 난이도
- `3`: 레인
- `4`: 연타
- `5`: 동시치기
- `6`: 홀드
- `7`: 노트 누락
- `8`: 불필요 노트

플레이가 끝나면 체감 난이도와 통과 여부를 선택하고 review-v1 JSON을 내려받는다. 리뷰에는 로컬 파일 경로와 오디오 원본이 포함되지 않는다.
