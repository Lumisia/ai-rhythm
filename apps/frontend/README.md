# 로컬 채보 플레이테스터

이 앱은 `playtest-run-v1.json`이 있는 로컬 워커 실행 폴더를 서버 업로드 없이 검사하고 수동 플레이하는 도구다.

## 브라우저 실행 전 검증

Node.js 24 환경에서 다음 명령으로 실행 폴더를 먼저 검사한다.

```powershell
npm run validate:run -- "C:\Git\ai-rhythm\.data\playtests\koe-no-yukue-v3"
```

검증기는 매니페스트가 참조하는 오디오와 12개 채보만 읽는다. JSON Schema, SHA-256, 키 모드·난이도 조합, 노트 시간과 레인, HOLD 종료 시각, 지표의 노트 수를 확인한다. 난이도 목표 초과, 측정 티어 불일치, 난이도 간 rating 역전은 실패가 아니라 수동 확인용 경고로 출력한다.

## 화면 읽는 법

플레이필드는 게임 화면이 아니라 계기판이다.

- **상단 좌측** — ACC, 경과/전체 시간, 판정한 노트 수, 최대 콤보, 판정별 집계.
- **판정선 위** — 콤보와 직전 판정. 판정 아래에 오차 ms와 EARLY/LATE가 붙는다. 롱노트를 뗀 판정은 `⌐떼기`가 붙는데, 떼기는 판정 창이 1.5배 넓어 머리 판정과 기준이 다르다.
- **판정선 아래 스코프** — 이 화면의 핵심. 가운데가 0ms고 최근 타격이 오차 위치에 점으로 남는다. 안쪽 민트색 눈금이 PERFECT 경계다. 민트색 삼각형이 평균이고, 그 아래 권장 보정값이 나온다.
- **레인 점등** — 키를 누르면 판정과 무관하게 레인이 밝아진다. 안 밝아지면 키 바인딩 문제지 채보 문제가 아니다.
- **맨 아래 레일** — 곡 진행. 붉은 눈금이 기록한 문제 마커 위치다.

## 입력 보정 맞추는 순서

체감으로 맞추지 말고 스코프를 본다.

1. 아무 채보나 30초쯤 친다.
2. 스코프 점들이 한쪽으로 쏠렸는지 본다. 평균 삼각형이 오른쪽이면 계속 늦게 치고 있다.
3. 화면이 알려주는 권장 보정값을 입력 보정에 넣는다.
4. 다시 쳐서 점 무리가 가운데로 모이는지 확인한다.

**보정을 맞추기 전 판정 결과는 신뢰하지 않는다.** 오프셋이 틀린 상태로는 채보의 박자 문제와 내 입력 지연을 구분할 수 없다.

## 수동 플레이 순서

`npm run dev`를 실행하고 워커 실행 폴더를 선택한다. 공통 타이밍과 입력감을 비교하기 위해 다음 순서를 권장한다.

1. NORMAL 4K
2. NORMAL 6K
3. NORMAL 7K
4. 각 키 모드의 EASY → HARD → EXPERT

채보 카드의 `측정` 값이 붉으면 라벨과 실제 난이도가 어긋난 것이다. 자동 품질 게이트는 요청 티어 일치를 요구하지만 목표 중앙값보다 어려운 결과에는 별도 경고가 남을 수 있다. `HOLD`가 붉으면 그 채보에 롱노트가 없다는 뜻이다.

### 키 배열

| 키 모드 | 배열 |
| --- | --- |
| 4K | `A` `S` `;` `'` |
| 6K | `A` `S` `D` `L` `;` `'` |
| 7K | `A` `S` `D` `Space` `L` `;` `'` |

7K는 6K에 가운데 엄지만 더한 것이다. 모두 홈 포지션 안이라 손가락이 자리를 떠나지 않는다.

입력은 `KeyboardEvent.code`를 사용하므로 한글·영문 입력 모드가 바뀌어도 물리 키 배열은 같다. 플레이 중 창을 벗어나면 눌린 레인을 입력 기록, 판정 엔진, 화면에서 모두 자동 해제한다.

`ESC`로 일시정지한다. 플레이 중 숫자 키로 문제 구간을 기록하며, 기록되면 우측 상단에 이름이 잠깐 뜬다.

- `1`: 박자
- `2`: 난이도
- `3`: 레인
- `4`: 연타
- `5`: 동시치기
- `6`: 홀드
- `7`: 노트 누락
- `8`: 불필요 노트

플레이가 끝나면 체감 난이도와 통과 여부를 선택하고 review-v1 JSON을 내려받는다. 리뷰에는 로컬 파일 경로와 오디오 원본이 포함되지 않는다.

## 키음 stem

설정의 `키음 stem 사용`이 `UNAVAILABLE`이면 실행 폴더에 스템이 없는 것이다. Mapperatorinator를 다시 돌릴 필요 없이 후처리만 다시 실행해 붙일 수 있다.

```powershell
uv run chart-worker postprocess ".data\playtests\koe-no-yukue-real" --out ".data\playtests\koe-no-yukue-v3" --keysounds
```

켜면 BGM이 드럼 뺀 스템으로 바뀌고, 노트를 칠 때마다 드럼이 울린다. 노트가 없는 드럼 onset은 자동 재생된다. Demucs는 CPU에서 3분 곡 기준 100초쯤 걸린다.
